# split_part

## 功能

根据分割符拆分字符串，返回指定的分割部分。`field` 从 1 开始计数：正数从字符串头部开始数，负数从字符串尾部开始数。

## 语法

```Haskell
split_part(content, delimiter, field)
```

## 参数说明

`content`: 支持的数据类型为 VARCHAR。

`delimiter`: 支持的数据类型为 VARCHAR。

`field`: 支持的数据类型为 INT。

## 返回值说明

返回值的数据类型为 VARCHAR。

- 如果 `field` 为 0，返回空字符串。
- 如果分隔符在字符串中不存在：
  - `field` 为 1 或 -1 时，返回原字符串（原字符串作为唯一的分割部分）。
  - 其他值返回空字符串。
- 如果 `field` 超过实际分割部分的数量（正数大于总分段数，或负数的绝对值大于总分段数），返回空字符串。
- 如果分隔符为空字符串，按 UTF-8 字符切分字符串，`field` 从头部（正数）或尾部（负数）数字符；越界时返回空字符串。
- 如果任一参数为 NULL，返回 NULL。

## 示例

```Plain Text
MySQL > select split_part("hello world", " ", 1);
+----------------------------------+
|split_part('hello world', ' ', 1) |
+----------------------------------+
| hello                            |
+----------------------------------+

MySQL > select split_part("hello world", " ", 2);
+-----------------------------------+
| split_part('hello world', ' ', 2) |
+-----------------------------------+
| world                             |
+-----------------------------------+

MySQL > select split_part("2019年7月8号", "月", 1);
+-----------------------------------------+
| split_part('2019年7月8号', '月', 1)     |
+-----------------------------------------+
| 2019年7                                 |
+-----------------------------------------+

MySQL > select split_part("abca", "a", 1);
+----------------------------+
| split_part('abca', 'a', 1) |
+----------------------------+
|                            |
+----------------------------+

MySQL > select split_part("hello world", ",", 1);
+-----------------------------------+
| split_part('hello world', ',', 1) |
+-----------------------------------+
| hello world                       |
+-----------------------------------+

MySQL > select split_part("hello world", " ", 3);
+-----------------------------------+
| split_part('hello world', ' ', 3) |
+-----------------------------------+
|                                   |
+-----------------------------------+

MySQL > select split_part("hello world", " ", 0);
+-----------------------------------+
| split_part('hello world', ' ', 0) |
+-----------------------------------+
|                                   |
+-----------------------------------+

MySQL > select split_part("abc", "", 2);
+---------------------------+
| split_part('abc', '', 2) |
+---------------------------+
| b                         |
+---------------------------+
```
